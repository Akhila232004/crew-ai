**Groq API Key Setup **

## Step 1: Create a Groq Account
https://console.groq.com/keys
Go to the Groq website and create an account or log in using Google, GitHub, SSO, or your email address.
![Screenshot](<Screenshot 2026-08-19 155102.png>)

## Step 2: Open the API Keys Page
After logging in to your Groq account, you will be redirected to the Groq dashboard.
Click on API Keys from the navigation bar at the top.
![Screenshot](<Screenshot 2026-08-19 155214.png>)

 ## Step 3: Create a New API Key
 On the API Keys page, click the Create API Key button.
 This will open a form where you can configure your new API key.
 ![Screenshot](<Screenshot 2026-08-19 155259.png>)

 ## Step 4: Enter an API Key Name
 Enter a meaningful name for your API key in the Display Name field.
 For example: crew-ai-project
You can keep Expiration as No expiration or choose another expiration option if required.
![Screenshot](<Screenshot 2026-08-19 155314 - Copy - Copy - Copy.png>)

## Step 5: Submit and Generate the API Key
After entering the display name and selecting the expiration option, click the Submit button to generate your API key.
![Screenshot](<Screenshot 2026-08-19 155347 - Copy - Copy - Copy.png>)

**Mistral API Key Setup**

## Step 1: Create or Log in to your Mistral AI account
Go to the Mistral AI platform and create an account or log in using your email or one of the available sign-in options.
https://mistral.ai/
![Screenshot](<Screenshot 2026-08-19 161153 - Copy - Copy.png>)

## Step 2: Accept the Terms of Service
After logging in, accept the Mistral AI Terms of Service and Privacy Policy by clicking Accept and continue.
![Screenshot](<Screenshot 2026-08-19 161322.png>)

## Step 3: Open the API Keys section
Once you enter Mistral Studio, click API Keys from the left sidebar.
!![Screenshot](<Screenshot 2026-08-19 161412.png>)

## Step 4: Create a new API key
In the My API Keys section, click the Create new key button to generate a new API key.
![Screenshot](<Screenshot 2026-08-19 161509.png>)

 ## Step 5: Copy and save your API key
After the API key is created, click the Copy button and save the key somewhere secure. The full API key may only be shown once.
![Screenshot](<Screenshot 2026-08-19 161656.png>)

## Step 6: Verify that the API key was created
After clicking Done, your newly created API key will appear in the Active keys list. This confirms that your API key has been created successfully.
![Screenshot](<Screenshot 2026-08-19 161716.png>)

**Creating an API Key in OpenRouter**

## Step 1: Open the OpenRouter Website
https://openrouter.ai/
Open the OpenRouter platform and click Sign Up if you do not already have an account. If you already have an account, sign in using your preferred method such as Google, GitHub, MetaMask, or email.
![Screenshot](<Screenshot 2026-08-19 162106.png>)

## Step 2: Accept the Legal Consent
After signing up, read and accept the Terms of Service, Privacy Policy, and Model Terms by selecting the checkbox. Then click Continue.
![Screenshot](<Screenshot 2026-08-19 162155.png>)

## Step 3: Skip Payment Setup
OpenRouter may ask you to add a payment method. If you do not want to add one at this stage, click “I’ll do this later” to continue.
![Screenshot](<Screenshot 2026-08-19 162328.png>)

## Step 4: Go to the Dashboard
Once your workspace setup is complete, you will see the “You’re all set!” message. Click Go to Dashboard to access your OpenRouter workspace.
![Screenshot](<Screenshot 2026-08-19 162351.png>)

## Step 5: Navigate to API Keys
From the left-side navigation menu, select API Keys. This section allows you to view, manage, and create API keys for your workspace.
![Screenshot](<Screenshot 2026-08-19 162418.png>)

## Step 6: Create a New API Key
On the API Keys page, click the + New Key button located in the top-right corner.
![Screenshot](<Screenshot 2026-08-19 162438.png>)

## Step 7: Configure the API Key
Enter a name for your API key, for example, crew-ai-project. You can also configure options such as:
Expiration – Set an expiration date or select No expiration.
Credit limit – Optionally set a usage or spending limit.
Reset limit – Configure how often the credit limit should reset.
After entering the required details, click Create.
![Screenshot](<Screenshot 2026-08-19 162519.png>)

## Step 8: Copy and Store the API Key Securely
After the API key is created, copy it and store it securely.

**NVIDIA NIM API Key creation**

## Step 1: Open NVIDIA AI
Visit the NVIDIA AI platform and click Login to sign in or create a new account.
https://build.nvidia.com/settings/api-keys
![Screenshot](<Screenshot 2026-08-19 162742.png>)

## Step 2: Enter Your Name
Enter your name in the required field and click Next to continue.
![Screenshot](<Screenshot 2026-08-19 162857.png>)

## Step 3: Create an NVIDIA Account
Enter your email address, create and confirm a password, complete the verification, and click Create Account.
![Screenshot](<Screenshot 2026-08-19 163123.png>)

## Step 4: Verify Your Email
Enter the 6-digit verification code sent to your registered email address and click Continue.
![Screenshot](<Screenshot 2026-08-19 163223.png>)

## Step 5: Create an NVIDIA Cloud Account
Provide a suitable Cloud Account Name for your project and click Create NVIDIA Cloud Account.
![Screenshot](<Screenshot 2026-08-19 163337.png>)

## Step 6: Access Your Account Menu
After signing in, click the profile icon in the top-right corner and select your workspace/account.
![Screenshot](<Screenshot 2026-08-19 163646.png>)

## Step 7: Open API Keys
From the account or workspace menu, select API Keys to manage and create API keys.
![Screenshot](<Screenshot 2026-08-19 163717.png>)

## Step 8: Generate an API Key
On the API Keys page, click Generate API Key.
![Screenshot](<Screenshot 2026-08-19 163739.png>)

## Step 9: Configure the API Key
Enter a suitable Key Name (for example, crew.ai), select the expiration period, and click Generate Key.
![Screenshot](<Screenshot 2026-08-19 163854.png>)

## Step 10: Copy and Save the API Key
The generated API key will be displayed only once. Click Copy API Key and store it securely in a safe location. Do not share the key publicly.
